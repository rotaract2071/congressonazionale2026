# Context
La pagina sponsor servirà agli invitati dell'evento Congresso Nazionale Siena 2026 a visualizzare la lista degli sponsor che hanno supportato l'evento.

Gli sponsor sono suddivisi in tre tier:
- Tier A: massima priorità
- Tier B: priorità intermedia
- Tier C: priorità inferiore

Sarà stampato un QR code con l'URL della pagina, che sarà visualizzata esclusivamente da smartphone.

Tutti gli sponsor devono essere mostrati in questa singola pagina.

Layout:
- Tier A: prima sezione, immagini full-width
- Tier B: seconda sezione, immagini half-width
- Tier C: terza sezione, immagini 1/3 width

Ogni tier devr essere introdotto dai seguenti copy
- Tier A: "ringraziamo queste realtà per lo straordinario supporto:"
- Tier B: "ringraziamo queste realtà per il supporto:"
- Tier C: "ringraziamo queste realtà per i loro prodotti:"

# Implementation notes
- I nomi dei tier non devono apparire in alcun modo nella pagina.
- Usa le grid CSS per disporre le griglie con i loghi
- Il look 'n' feel dev'essere minimalista, moderno, sobrio ed elegante.
- La pagina sarà interamente implementata in sponsor/index.html
- La pagina deve essere progettata assumendo che sarà visualizzata solo da smartphone
- Usa con saggezza lo spacing e in modo semantico
- Usa tag HTML semantici
